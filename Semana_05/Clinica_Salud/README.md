# Clínica Salud+

Clínica Salud+ es una aplicación móvil desarrollada con Kotlin y Jetpack Compose para facilitar la consulta de médicos y la gestión de citas médicas. La aplicación implementa navegación secuencial, navegación secundaria mediante NavigationDrawer, LazyRow, LazyColumn y selección única para la reserva de citas.

# Requerimientos funcionales
- RF01. Consulta de médicos
- RF02. Perfil y navegación del médico
- RF03. Agendamiento de citas
- RF04. Confirmación y gestión de citas
