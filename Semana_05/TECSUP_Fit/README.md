# TECSUP Fit

TECSUP Fit es una aplicación móvil desarrollada con Kotlin y Jetpack Compose para consultar clases de entrenamiento y gestionar reservas. La aplicación utiliza navegación secuencial, bottomBar, LazyRow y LazyColumn.

## Requerimientos funcionales
- RF01. Consulta de clases
- RF02. Detalle y reserva
- RF03. Confirmación y navegación
- RF04. Reservas y perfil
