# PROMT

Convierte el proyecto `Semana_05/Sin_IA` en `Semana_05/Con_IA`, manteniendo las funcionalidades del laboratorio de Manejo de Estados con Jetpack Compose.

Aplica POO creando una `data class Tarea` con `id`, `nombre` y `completada`. Usa objetos `Tarea` para registrar y mostrar las tareas, `copy()` para actualizar su estado, `Checkbox` para completarlas, `LazyColumn` para listarlas y un botón para eliminarlas.

Mantén la interfaz y funcionalidades del laboratorio, pero organiza el código para demostrar claramente la aplicación de POO.
