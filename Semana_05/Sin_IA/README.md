# Manejo de Estados en Jetpack Compose

Aplicación básica de control de tareas desarrollada con Jetpack Compose. Permite agregar tareas, visualizar la cantidad registrada, marcar tareas como completadas y eliminarlas utilizando el manejo de estados para actualizar automáticamente la interfaz.
