# Registro de Notas — Jetpack Compose

## Descripción

Aplicación desarrollada en Kotlin y Jetpack Compose para registrar notas de cuatro cursos, calcular el promedio ponderado y mostrar la observación final. La versión utiliza clases y lógica orientada a objetos (POO).

## Funcionamiento

Permite ingresar notas mediante Slider, confirmar los datos, activar el redondeo y calcular el promedio final.
