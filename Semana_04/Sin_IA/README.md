# Registro de Notas — Jetpack Compose

## Descripción

Aplicación desarrollada en **Kotlin y Jetpack Compose** que permite registrar las notas de cuatro cursos mediante `Slider`, confirmar las notas con `Checkbox`, seleccionar el redondeo mediante `Switch` y calcular el promedio ponderado final, mostrando la observación correspondiente.

## Funcionamiento

La aplicación permite ingresar las notas, confirmar los datos y calcular el promedio final según los porcentajes establecidos para cada curso.
