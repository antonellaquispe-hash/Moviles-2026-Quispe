# Mi Bodega — App Cliente

Aplicación móvil desarrollada en Kotlin utilizando Jetpack Compose como parte del curso de Desarrollo de Aplicaciones Móviles en TECSUP.

## Descripción

Mi Bodega es una aplicación móvil orientada a clientes de una tienda. Permite visualizar productos, filtrarlos por categorías, consultar el detalle de un producto, agregarlos al carrito y completar un pedido.

La aplicación utiliza información almacenada en memoria mediante datos ficticios.

## Tecnologías utilizadas

- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
