# PROMPTS - Mejora con IA

## Prompt utilizado

Diseñar una mejora para la aplicación TECSUP Store utilizando Jetpack Compose, incorporando un contador de favoritos y conectándolo con la opción Favoritos del NavigationDrawer.

## Mejora implementada

Se agregó un sistema de favoritos que permite:

- Agregar productos a favoritos.
- Mostrar la cantidad de favoritos.
- Visualizar los productos favoritos.
- Quitar productos de favoritos.
- Actualizar automáticamente el contador.

## Resultado

La mejora permite que el usuario gestione sus productos favoritos desde la aplicación y tenga acceso a ellos mediante el NavigationDrawer.
