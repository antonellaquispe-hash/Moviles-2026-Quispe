# TECSUP Store

Aplicación móvil desarrollada con **Kotlin y Jetpack Compose** para el laboratorio de Desarrollo de Aplicaciones Móviles de TECSUP.

### Funcionalidades

* Lista de productos y categorías.
* Menú `DropdownMenu` en cada producto.
* NavigationDrawer con Inicio, Mis pedidos, Favoritos y Perfil.
* Navegación entre pantallas.
* Interfaz desarrollada con Material 3.
